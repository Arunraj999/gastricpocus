# NORA² Regional Anaesthesia website

Teaching website of the Northwest Regional Anaesthesia Alliance (NORA²), including the point-of-care ultrasound (POCUS) section with gastric ultrasound.

Editor: Dr Arun Mohanraj FRCA EDRA, Wrightington, Wigan and Leigh NHS Foundation Trust.

This is a static site. `index.html` is the home page; `pocus-gastric.html` is the gastric ultrasound guide. To update a page, see `HOW-TO-UPDATE.txt`.
